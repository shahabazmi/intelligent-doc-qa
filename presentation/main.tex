% --- Slide 2: Problem & Goal -------------------------------------------------
\begin{frame}{\stepbadge{brand}{1} Why We Built This}
\vspace{-1mm}\scriptsize
Public AI assistants and hosted RAG services have three real problems for
anyone working with private documents:
\smallskip

\stepcard{query}{lock}{1}{Privacy.}{%
Your file leaves your computer --- the provider receives, stores, and may
train on it. Unacceptable for confidential material.}{%
the document\\never stays\\on your laptop}

\stepcard{query}{brain}{2}{Hallucination.}{%
Small LLMs add hedge phrases (``could lead to'', ``analysts believe'')
not in the source --- and you can't see which sentence grounded the answer.}{%
you can't verify\\where the answer\\came from}

\stepcard{query}{coins}{3}{Cost.}{%
Hosted RAG charges per token, per page, per query. Indexing 1{,}000 pages
and asking 50 follow-up questions adds up fast --- you can't experiment freely.}{%
every page +\\every question\\= money}

\vspace{2mm}
\centering\scriptsize\itshape\color{textSoft}
\emph{Our goal:} a complete document QA system where every piece runs on
the user's laptop --- on the user's data, with zero cost per query.
\end{frame}

% --- Slide 4: Upload journey -------------------------------------------------
\begin{frame}{\stepbadge{ingest}{3} How an Uploaded PDF Becomes Searchable}
\vspace{-1mm}\scriptsize
\textbf{Walk-through.} The user drags \texttt{NASDAQ\_TSLA\_2024.pdf}
(Tesla 10-K, 1.7\,MB) into the chat. Five things happen, in order:
\smallskip

\stepcard{ingest}{file}{1}{Check the file.}{%
Look at the file type (PDF/DOCX/TXT/image) and SHA-256-hash the bytes. If
this exact file was uploaded before, reuse it and skip the rest.}{Tesla 10-K\\$\to$ new, continue}

\stepcard{ingest}{book}{2}{Read the pages.}{%
\texttt{PyMuPDF} walks every page and pulls the text out. Tables are
extracted \emph{separately} so revenue rows stay together.}{$\sim$1{,}400 raw\\text + table blocks}

\stepcard{ingest}{cut}{3}{Slice the text into small chunks.}{%
A 200-page PDF is too big to search at once. Split into windows of
\textbf{500 chars} with \textbf{100 overlap} --- one paragraph per chunk.}{$\to$ 1{,}180\\searchable chunks}

\stepcard{ingest}{cogs}{4}{Convert each chunk into numbers.}{%
The model \texttt{bge-small-en-v1.5} turns each chunk into \textbf{384
numbers} that capture its meaning. ``CEO'' and ``Chief Executive'' end up
nearby.}{1{,}180\,$\times$\,384\\numbers}

\stepcard{ingest}{database}{5}{Save everything locally.}{%
Text $\to$ SQLite (source of truth). Numbers $\to$ Milvus Lite (fast
similarity search). The file is now ready to answer questions.}{ready in\\$\approx\!40$\,s}
\end{frame}

% =============================================================================
% --- Slide 5: Query journey --------------------------------------------------
\begin{frame}{\stepbadge{query}{4} How a Question Becomes a Grounded Answer}
\vspace{-1mm}\scriptsize
\textbf{Walk-through.} The user types \textit{``Who is the CEO of
NVIDIA?''}. Five things happen, in order:
\smallskip

\stepcard{query}{route}{1}{Decide what kind of message this is.}{%
Is it a doc question, chat (``hello''), or live data (``weather'')? ``Who
is the\ldots'' + PDF loaded $\Rightarrow$ \emph{document question}.}{not chat,\\not weather}

\stepcard{query}{tags}{2}{Decide what KIND of question.}{%
Seven types: extractive, numerical, provenance, list, reasoning, summary,
factual. ``CEO'' is a short fact $\Rightarrow$ \textsc{factual}.}{type = Factual\\$(k=3)$}

\stepcard{query}{search}{3}{Search the chunks --- two ways at once.}{%
\textbf{Keyword (BM25)} finds chunks with literal ``CEO''. \textbf{Meaning
(Milvus)} finds chunks about \emph{leadership}. Both lists are merged.}{$\sim$50\\candidates}

\stepcard{query}{filter}{4}{Pick the THREE sharpest passages.}{%
A \emph{cross-encoder} reads each candidate \emph{with} the question and
scores them tightly. Slower, but much sharper than the first two searches.}{top 3 chunks}

\stepcard{query}{chat}{5}{Generate the answer --- strictly.}{%
The local LLM (\texttt{llama3.2:3b}) sees \emph{only} those 3 chunks with
a 10-rule prompt and $T=0$. No outside knowledge.}{$T=0$,\\strict prompt}

% --- Slide 6: Problems we solved ---------------------------------------------
\begin{frame}{\stepbadge{query}{5} What Broke When I Tested --- and How I Fixed It}
\vspace{-1mm}\scriptsize
Three real bugs, each tied to one of the test PDFs, diagnosed in code and
verified after the fix.
\smallskip

\stepcard{query}{tesla}{1}{Tesla 10-K --- revenue tables collapsed into one line.}{%
\emph{Test:} ``Tesla revenue 2024?''
\emph{Bug:} Rows like \texttt{21,344 23,210 17,933 25,500} merged into one
string. \emph{Fix} (\texttt{chunker.py}): keep line breaks if $\geq\!3$
short numeric lines.}{\bfseries After:\\\$77{,}070\,M}

\stepcard{query}{nvidia}{2}{NVIDIA --- the LLM invented hedge phrases.}{%
\emph{Test:} ``Who is the CEO of NVIDIA?''
\emph{Bug:} Model added ``could lead to'', opened with ``Based on the
doc\ldots''. \emph{Fix} (\texttt{generator.py}): strict prompt + ban-list +
regex opener cleaner.}{\bfseries After:\\``Mr.\ Huang\\\ldots President\\and CEO.''}

\stepcard{query}{ncic}{3}{NCIC PIA --- model paraphrased a verbatim quote.}{%
\emph{Test:} ``Show the exact paragraph about NCIC.''
\emph{Bug:} Model re-worded the paragraph. \emph{Fix}
(\texttt{query\_classifier.py}): \textsc{extractive}+\textsc{provenance}
types bypass the LLM, return raw chunk.}{\bfseries After:\\$\approx\!200$\,ms\\100\% faithful}

\smallskip
{\scriptsize\color{textMute}
\textbf{\color{ingest}\#4 Bi-encoder misses}\,---\,fixed with parallel
BM25\,+\,vector\,+\,page-1/acronym/\texttt{@} bonuses, then cross-encoder
rerank.\quad
\textbf{\color{ingest}\#5 State loss}\,---\,catch Milvus drops, reset
\& retry; cap LLM context at 3{,}000 chars; auto-rebuild from SQLite on
startup.}
\end{frame}

\textbf{\color{brand}4. What Broke and How I Fixed It.}
\begin{itemize}\setlength{\itemsep}{0pt}

\item Paraphrased quotes $\Rightarrow$ LLM-bypass for 2 query types.
\item Tables $\to$ gibberish $\Rightarrow$ numeric-line heuristic.
\item State loss $\Rightarrow$ SQLite-as-truth + auto-rebuild.
\end{itemize}
